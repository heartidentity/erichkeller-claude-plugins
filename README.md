# erichkeller Claude-Plugins

Plugin-Marketplace für die Redaktion von erichkeller.ch.

**⚠️ Nicht von Hand editieren.** Inhalte unter `plugins/` werden automatisch
aus [`heartidentity/erichkeller-website`](https://github.com/heartidentity/erichkeller-website)
(`editors-plugin/`, Branch `develop`) publiziert — Änderungen gehören dorthin.

## Installation (Editoren)

Einmalig in Cowork bzw. Claude Code:

1. Marketplace hinzufügen: `heartidentity/erichkeller-claude-plugins`
2. Plugin **redaktion** installieren
3. Beim ersten DatoCMS-Zugriff mit dem eigenen DatoCMS-Konto einloggen (OAuth)

Danach stehen die Skills `/referenz-erfassen` und `/seite-bauen` zur
Verfügung. Updates kommen automatisch beim Start von Cowork.
